## 快速開始

**線上使用。** 開啟 [noureon.com](https://noureon.com/)，用名稱和密碼建立本機個人檔案（或綁定 Email、Google 帳號使用雲端帳號），到 **設定 → 模型管理** 為至少一個供應商加入 API 金鑰，在訊息框旁選一個模型就能開始對話。網站上的 [協助中心](https://noureon.com/help) 說明每一個功能。

**自己執行。** Noureon 是以 MIT 授權釋出的開源專案。

```bash
git clone https://github.com/NHZallen/Noureon.git
cd Noureon
npm ci
npm run dev
```

然後開啟 `http://localhost:5173`。更多內容見[在本機執行](#在本機執行)。

## Noureon 是什麼

多數 AI 對話應用都圍繞著單一廠商的單一模型打造。Noureon 是為了需要選擇、比較與模型之間合作的工作而做的，也為了想自己掌控資料的人。

- **自備金鑰。** Noureon 不販售模型用量，也不提供模型額度。你為想用的每個供應商加入 API 金鑰，費用直接付給該供應商。
- **本機優先。** 對話、專案、設定、助手、API 金鑰與外觀偏好預設都存在你的瀏覽器裡。
- **帳號是選擇性的。** 雲端帳號可以解鎖跨裝置同步、關閉頁面後仍會繼續的回覆、雲端檔案儲存、需要伺服器的擴充功能與分享。不用帳號也能使用 Noureon。
- **同一個工作空間。** 對話、搜尋網路、讀附件、研究主題、製作檔案與簡報、畫圖、執行程式、使用連接的服務，都不必切換工具。
- **到處都能用。** 它是漸進式網頁應用（PWA）：在電腦或手機的瀏覽器使用，或從瀏覽器安裝。

## 功能

### 模型與供應商

在同一份對話清單裡使用不同廠商的模型，隨時切換。

| 服務 | 提供什麼 |
| --- | --- |
| Google Gemini | Gemini 模型，附內建的網路搜尋 |
| OpenRouter | 一把金鑰使用許多實驗室的模型，以及圖片模型 |
| OpenAI | OpenAI 的文字與圖片模型，附 OpenAI 自己的網路搜尋 |
| NVIDIA | NVIDIA 目錄中的免費託管模型 |
| OpenCode Go | 以 OpenCode Go 訂閱使用多家廠商的模型 |
| Tavily、TinyFish | 為沒有自帶搜尋的模型提供網路搜尋與網頁讀取 |

- 訊息框旁的模型選單列出所有可用模型（超過 80 個選項、約 20 家廠商），可搜尋，也可依廠商分組。支援思考程度的模型會顯示滑桿，調整它想得多深。
- 只需設定你打算使用的供應商。可用模型、價格、限額與地區限制由各供應商決定。
- 可在設定中選擇一個小型「判斷模型」，協助判斷例如一則訊息要不要搜尋網路。它太慢或失敗時，App 會改用自己的詞表判斷。

### 對話

- **訊息框：** 貼上文字、附加檔案、拍照、語音輸入，輸入 `/` 選技能、`@` 選命令工具，也能把輸入框展開成大視窗。手機上，**＋** 會開啟底部面板，內有相機、相簿、檔案、Google 雲端硬碟、搜尋、議會、深度研究、學習與設計。
- **回覆進行中引導：** 回覆還在跑時送出訊息，可以引導它（模型在下次用完工具時看到你的訊息）、排隊等回覆結束後再送，或停止回覆並立刻送出。預設做法在設定裡選。
- **Noura：** 可重複使用的助手，有自己的名稱、說明、指示與頭像。可從 Noura 商店挑選官方的、自己建立、提案新的，也可以在裝置之間直接交給別人。
- **整理：** 把對話放進專案、封存或移到垃圾桶；可一次選取多個移動；垃圾桶可還原或永久刪除。
- **臨時對話：** 不留任何紀錄，回覆在你自己的裝置上產生。
- **搜尋歷史：** 以標題、訊息內容搜尋，或用自然語言詢問；時間軸讓你跳到長對話中的某則訊息。
- **學習模式：** 訊息框的一種模式，用來一步一步學習一個主題。
- **分支與編輯：** 編輯訊息後從那裡繼續，或把對話分支成新對話，複製到你選的那則訊息為止。
- **自動命名：** 對話會有簡短的標題，可以關閉。
- **個人數據面板：** 總數、最常用的模型、各模型使用占比與書寫時段，全部在你自己的裝置上統計。
- **分享對話：** 產生連結，連到唯讀副本，或是擁有雲端帳號的人可以複製並用自己的金鑰接著聊的版本。記憶、助手指示與你的金鑰永遠不會被分享。隨時可更新連結或停止分享。

### 模型議會

模型議會讓 2 到 5 個模型對同一個問題各自提出看法，再由你指定的整合模型寫出一份答案。

- **共識模式：** 每位成員各自回答，整合者把答案整理起來。
- **討論模式：** 成員先回答、互相閱讀、修正，最後由整合者寫出結論。
- **共識與差異表：** 答案附帶一張表，說明誰同意、誰保留，以及如何取捨。
- **成員會做事：** 開啟網路搜尋時，每位成員自己搜尋、自己開網頁；成員也能載入你的技能，並在你允許時讀取連接的服務。成員只讀不改。
- **即時時間軸：** 執行時能看到各階段與每位成員正在做什麼；結束後回覆保留一行摘要，點開就是時間軸。
- **儲存的組合：** 把一組成員與整合者存起來，之後一鍵套用。
- **不靠頁面也能跑：** 使用雲端帳號時，議會在伺服器上進行，即使關閉頁面也會跑完。

### 深度研究

適合需要大量查找、並要有出處的報告的問題。

1. 模型先擬一份最多八項的研究計畫，你有一小段倒數時間可以修改。
2. 它逐項進行：搜尋、讀網頁、交叉比對、寫下筆記。
3. 你可以即時看進度（完成項目、百分比、搜尋次數、用時），並打開來源與活動。可以暫停、停止，或送出額外指示。
4. 結果是附引用與圖表的報告。可以在對話裡讀，也可以全螢幕閱讀（有目錄），並匯出成 PDF、Word 或 Markdown。

使用雲端帳號時，研究在伺服器上進行，你可以離開、之後回來看完成的報告。它需要一個網路搜尋來源：Gemini 與 OpenAI 模型有自己的，其他模型使用 Tavily 或 TinyFish 金鑰。

### 網路搜尋與讀取網頁

- 有內建搜尋的模型（Gemini、OpenAI）可以直接使用；其他模型使用你選擇的 Tavily 或 TinyFish。
- **智慧搜尋**會判斷一則訊息到底要不要搜尋網路。
- 你貼在訊息裡的網址會替你讀取。
- 對不能使用工具的模型，會先搜尋，再把找到的網頁當成「搜尋資料包」交給它。
- 答案中引用的來源會編號，旁邊附網站名稱與小圖示。

### 附件、相機與語音

- 可附加圖片、文件、音訊與影片。模型能不能直接讀取檔案，取決於模型本身。
- 模型讀不了文件時，可由你選擇的「文件轉譯」模型，只針對那一次請求把文件轉成詳細文字。Word、PowerPoint 與 Excel 檔（文字、表格、圖表、圖片）也會替不能開啟它們的模型讀出來。
- 每個附件都會替模型編號（「本則訊息 3 張圖片中的第 2 張」），所以你可以說「第二張圖」或「合約寫了什麼？」。
- **相機：** 一步拍照並附加。
- **語音輸入：** 用麥克風聽寫，由瀏覽器把語音轉成文字。
- **錄音的語音轉文字**（預設關閉）：把你附加的錄音與影片中的說話內容寫成文字，讓不能聽的模型也能讀；使用你自己的金鑰，或不需金鑰的 Whisper 模型。

### 檔案與簡報

在對話中請模型製作簡報（PPTX）、Word（DOCX）、Excel（XLSX）、PDF，或十幾種其他格式，例如 CSV、行事曆與字幕。

- 檔案以卡片呈現，可預覽、下載，也能一次把多個打包成一個 ZIP。
- **設計：** 20 種簡報設計與 9 種文件樣式，有設計面板可選，也可以用文字描述想要的風格。
- **視覺檢查：** 簡報做好後，每一頁可以畫成圖片，交給你指定的模型檢查版面並修正。
- **圖表：** 回覆與匯出的檔案裡都有互動圖表與圖解。
- 使用雲端帳號時，你製作的檔案會存進你自己的雲端儲存空間。

### 圖片生成與編輯

- 圖片模型（GPT Image、FLUX、Nano Banana 等）可以在對話中畫圖，支援參考圖、長寬比、解析度與品質設定，之後還能繼續編輯。
- **GIF 與 SVG：** 最新的 GPT Image 模型可以做動態 GIF（可選影格數與時間）與 SVG 向量圖。
- **編輯：** 標出圖片的一塊區域並要求修改；GIF 可以標記單一影格或一整格影格，並設定播放速度。
- 文字模型也能在你給它一個可呼叫的圖片模型時自己畫圖，圖會出現在它自己的回覆裡，並編號方便之後引用。
- 使用雲端帳號時，圖片在伺服器上產生，即使關閉頁面也會畫完。

### 進階模式（Python）

模型可以寫 Python 來處理資料、畫圖表、製作檔案。當模型與裝置都能執行時，Noureon 會自動使用，否則退回標準模式，所以沒有任何要選的地方。程式碼在隔離的環境中執行，可能在伺服器上，也可能在瀏覽器裡；製作出的檔案會列在回覆中。

### 擴充功能：技能、命令工具與連接器

擴充功能頁有三個部分。

- **技能：** 寫下來的工作方式（`SKILL.md`，有名稱、說明與指示）。Noureon 內建十一個官方技能，包含一個幫你寫技能的技能。用 `/` 選一個，或讓模型在需要時載入你允許的那些。也可以貼上文字，或上傳含說明、腳本與素材的 zip 來新增自己的技能。
- **命令工具：** 八個官方的命令列工具（例如 Pandoc、FFmpeg、yt-dlp、csvkit、SoX），在伺服器上的隔離環境執行。開啟後用 `@` 選一個，或讓模型使用。工具需要連到網站或登入時，Noureon 會先問你。
- **連接器：** 登入你自己在某個服務的帳號，模型就能讀取你在那裡的內容，並在你允許時修改。目前有 Google（行事曆、試算表、文件、簡報、雲端硬碟與 Gmail）、Notion、Linear、Miro、Canva、Context7、Upstash、Vercel、GitHub、Supabase、Hugging Face、Pally 與 ether.fi。你在該服務自己的頁面登入；每個工具你都可以決定允許、每次詢問，或拒絕。讀取類工具預設允許，會修改內容的工具預設詢問。

### 專案

專案把對話聚在一起，並給它們共用的脈絡。

- **指示：** 專案裡每個對話都遵守的指示。
- **資料來源：** 文字與檔案（原樣保存），以及用 Google 自己的檔案選擇器從 Google 雲端硬碟挑的檔案。模型會自己搜尋與讀取，包含圖片、影片畫格與掃描 PDF 的頁面。
- **專案記憶：** 專案可以有自己的筆記，其他對話看不到。
- **共享：** 以連結或 Email 邀請人，身分是編輯者或對話成員。每個人都能讀專案裡的對話，並把其中一個分支成自己的；每個對話仍屬於它的作者。擁有者管理成員與專案。
- 每個專案有自己的顏色與圖示。

### 記憶

- **筆記：** Noureon 把值得記住的、關於你的事記成簡短的筆記，一則一個事實。你可以查看、編輯、置頂、標為「不要提起」、刪除、匯出或清空。你刪掉的筆記不會再被學回來。
- **謹慎使用：** 置頂的筆記會跟著每則訊息；其他筆記只在跟你問的事有關時才查出來，你可以看到一則回覆用了哪些筆記，並標示某則與此無關。
- **學習：** 模型在對話中可能會存下一則筆記，每則筆記都必須引用你自己說過的話。學習、使用與暫停都可以各自關閉。自動整理會合併與封存筆記，它做的變更 30 天內可以復原。
- **過去的對話：** 關鍵字索引在你的瀏覽器裡由你的對話建立。依語意搜尋要你同意之後才會開啟。

### 帳號、同步與你的資料

- **本機帳號：** 一個名稱加密碼；資料只留在那個瀏覽器。
- **雲端帳號：** 綁定 Email 或 Google 帳號。登入方式包含通行金鑰與驗證器 App，設定裡會顯示目前登入的裝置。
- **雲端同步：** 對話、專案、助手、記憶筆記與你製作的檔案可跨裝置同步。API 金鑰要先建立同步密碼才會同步，而且離開裝置前就先加密。
- **匯出與匯入：** 把全部內容備份成 `.json` 或 `.zip`，之後再還原。
- **裝置之間：** 用短代碼或 QR code，在兩個裝置之間直接傳送或接收對話與助手。
- **分享項目：** 一個地方列出你分享過的每個連結，每個都能撤銷。
- **儲存空間：** 雲端檔案每個帳號有上限；設定裡會顯示你的用量。
- **全部刪除：** 一個按鈕就能永久清除瀏覽器裡的所有紀錄。

### 介面、語言與安裝

- **語言：** 繁體中文、English、Français、Русский、Español。
- **外觀：** 淺色、深色或跟隨系統，並可選強調色。
- **電腦：** 圖示列加上導覽面板（可常駐，也可滑過才展開）、整頁的設定，以及可以關閉或更改的鍵盤快捷鍵。
- **手機：** 跟著手指移動的底部面板，訊息框為單手操作設計。
- **安裝成 App：** 使用瀏覽器的「加入主畫面」或「安裝」。離線時只有已快取的 App 本身能用；需要模型或雲端的功能仍需要網路。
- **無障礙：** 可減少動態效果，也可選擇回覆進行中送出訊息的方式。

## 你的資料與隱私

本機優先的意思是，你的工作空間由你自己的裝置掌控，並不代表每個請求都能離線執行。

- 你送出訊息時，提示、對話脈絡與需要的附件會送到你選的模型供應商；網路搜尋請求會送到你選的搜尋來源。適用各供應商自己的條款與隱私權政策。
- API 金鑰預設留在你的瀏覽器裡。若你選擇讓回覆在伺服器上產生，金鑰只用於那一次回覆。
- 雲端同步、關閉頁面後仍會繼續的回覆、雲端檔案、分享與連接器，都只有雲端帳號才有，而且是選擇性的。
- 請閱讀完整的[隱私權政策](./PRIVACY.md)。協助中心與使用條款可在網站上查看。

## 在本機執行

### 需求

- Node.js `20.19+` 或 `22.12+`
- npm
- 至少一個支援的供應商的 API 金鑰

### 啟動

```bash
git clone https://github.com/NHZallen/Noureon.git
cd Noureon
npm ci
npm run dev
```

開啟 Vite 印出的網址，通常是 `http://localhost:5173`。然後：

1. 在登入頁建立本機個人檔案。
2. 開啟 **設定 → 模型管理**，為你想用的供應商加入 API 金鑰。
3. 在訊息框旁選一個模型，開始對話。

供應商的金鑰是在 App 裡輸入，不需要放進 `.env`。

### 不需額外服務就能用的功能

不做任何伺服器設定時，本機個人檔案就能使用對話、模型議會、搜尋、附件、檔案與簡報製作、圖片生成、記憶、專案、匯入匯出，以及瀏覽器內的 Python 模式。需要帳號的功能（雲端同步、關閉頁面後仍會繼續的回覆、雲端檔案儲存、分享、連接器、命令工具與在伺服器上執行的技能）需要雲端帳號與託管的執行環境，不屬於單純的本機設定。

## 設定

多數安裝不需要任何環境變數。選擇性的變數從 `.env` 檔讀取（見 `.env.example`）：

| 變數 | 用途 |
| --- | --- |
| `PORT` | 本機開發的連接埠 |
| `GOOGLE_FORM_ENDPOINT` | 讓內附的 API 路由把意見回饋與助手提案轉送到你自己的表單 |
| `VITE_SUPABASE_URL`、`VITE_SUPABASE_PUBLISHABLE_KEY` | 登入與同步服務的瀏覽器端設定（兩個值本來就是公開的） |
| `VITE_TURNSTILE_SITE_KEY` | 登入頁人機驗證用的公開網站金鑰 |
| `VITE_GOOGLE_PICKER_CLIENT_ID`、`VITE_GOOGLE_PICKER_API_KEY`、`VITE_GOOGLE_PICKER_APP_ID` | 專案裡從 Google 雲端硬碟選檔案用的公開設定 |

不要提交真正的服務端點、秘密或供應商金鑰。如果你自己託管 Noureon，請把秘密放在你的平台的環境設定裡。

## 開發

| 指令 | 用途 |
| --- | --- |
| `npm run dev` | 啟動 Vite 開發伺服器 |
| `npm run build` | 在 `dist/` 建立正式建置與公開頁面 |
| `npm run preview` | 預覽正式建置 |
| `npm test` | 執行回歸測試 |
| `npm run test:browser` | 執行瀏覽器端對端測試（需要 Chromium） |
| `npm run lint` | 執行 ESLint |
| `npm run check:shell` | 檢查對話頁外殼的邊界 |
| `npm run check:server` | 檢查與伺服器共用的模組沒有使用僅限瀏覽器的 API |
| `npm run check:sizes` | 檢查原始碼與套件大小預算 |
| `npm run check:version` | 檢查版本號在所有出現的地方一致 |
| `npm audit --omit=dev` | 稽核正式環境的相依套件 |

提交變更前請執行：

```bash
npm run build && npm test && npm run lint && npm run check:shell && npm run check:server && npm run check:sizes && npm run check:version && npm audit --omit=dev
```

測試如何配置見 [TESTING.md](./TESTING.md)。

## 專案結構

| 路徑 | 用途 |
| --- | --- |
| `src/app/runtime/` | 對話頁依領域劃分：回覆、議會、研究、圖片、訊息、設定、記憶、專案、分享、技能、命令工具、連接器等 |
| `src/app/runtime/shell/` | 頁面外殼：建立各個 store 與每個功能，並啟動頁面 |
| `src/app/ui/` | 介面元件：模型選單、面板、引用、圖表、檔案、專案、圖示列等 |
| `src/app/auth/`、`src/app/sync/` | 登入與雲端同步 |
| `src/app/share-page/` | 顯示被分享對話的頁面 |
| `src/data/` | 語言、技能／命令工具／連接器的目錄、助手與更新說明 |
| `src/styles/` | 依功能整理的樣式，共用的顏色名稱在 `tokens.css` |
| `server/` | 選擇性的伺服器執行環境，用於關閉頁面後仍會繼續的回覆 |
| `sandbox-host/`、`sandbox-probe/` | 隔離程式執行環境的檔案 |
| `api/` | 選擇性的 serverless 端點 |
| `public/` | PWA 資源、首頁資源與靜態檔案 |
| `scripts/` | 建置、邊界、大小與探測腳本 |
| `tests/` | 回歸、渲染、安全與行為測試 |

## 慣例

- 每一段使用者看得到的文字都有五種語言版本（`zh-TW`、`en`、`fr`、`ru`、`es`）。介面文字放在 `src/data/i18n/parts/`，每個領域一個檔案，五種語言並排。
- 顏色一律取自 `src/styles/tokens.css` 的名稱，不在樣式表裡寫死數值，淺色與深色主題才會同步。
- 新功能是自己的模組，只在核心檔案加一行註冊。大小預算由 `npm run check:sizes` 檢查。
- 瀏覽器與伺服器共用的模組不可使用 `window`、`document`、瀏覽器儲存或 `import.meta.env`；`npm run check:server` 會強制檢查。
